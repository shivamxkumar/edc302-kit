Short notes

Everything on one screen per topic. Highlighted values are the ones examiners love.

Structure

  • npn or pnp; two junctions, EBJ and CBJ.
  • Emitter heavily doped, base very thin, lightly doped, collector moderately doped.
  • Emitter injects, base controls, collector collects.

Modes of operation

Active-mode equations

iC = IS evBE/VTindependent of vCB
iB = iC/β β ≈ 50–200
iE = iC + iB = (β+1) iB
α = β/(β+1),   β = α/(1−α)

β = 100 gives α ≈ 0.99. Base current has two parts: iB1 (holes injected into the emitter) and iB2 (recombination in the base).

Saturation

  • npn stays active while vCB ≥ −0.4 V.
  • Below that, CBJ is forward biased, iC falls below βiB.
VCE(sat) = VBE − VBC ≈ 0.2–0.3 V
βforced = IC(sat)/IB < β

Early effect

Base-width modulation: iC rises slightly with vCE.

iC = ISevBE/VT(1 + vCE/VA),   ro = VA/IC

Remember

  • ICBO: collector-base reverse current with emitter open, nA range, doubles every 10 °C.
  • VBE falls about 2 mV/°C at constant current.
  • Large-signal models: voltage-controlled source (ISevBE/VT) or current-controlled (αiE or βiB).

Structure and channel

  • p-substrate, n⁺ source and drain, SiO₂ gate oxide (tox 1–10 nm), four terminals G, S, D, B.
  • vGS = 0: two back-to-back diodes, RDS ≈ 10¹² Ω.
  • vGS > Vt: holes repelled, electrons attracted, an inverted n-channel forms. Vt ≈ 0.3–1.0 V.
  • Gate current iG = 0, so iS = iD.

Key parameters

vOV = vGS − Vt
|Q| = Cox W L vOV
Cox = εox/tox,   εox = 3.45×10⁻¹¹ F/m
k′n = μnCox,   kn = k′n(W/L)A/V²

Small vDS and pinch-off

rDS = 1 / [k′n(W/L)vOV]
  • As vDS rises the channel tapers; at vDS = vOV the drain-end depth is zero (pinch-off).
  • Pinch-off does not block current; electrons are swept across the depletion region.
  • Triode/saturation boundary: iD = ½knvDS².

PMOS and CMOS

  • PMOS: n-substrate, p⁺ S/D, Vtp negative, conducts when vSG ≥ |Vtp|.
  • k′p = μpCox, with μp ≈ 0.25–0.5 μn, so NMOS is faster with more gain.
  • CMOS: both on one chip, PMOS in an n-well, isolated by thick oxide.

General structure

  • Feedback signal xf = βxo, mixer gives xi = xs − xf, output xo = Axi.
Af = A / (1 + Aβ)
  • Loop gain = Aβ. Amount of feedback = 1 + Aβ.
  • If Aβ ≫ 1, Af ≈ 1/β: set by passive parts only.

Properties of negative feedback

dAf/Af = (dA/A) / (1+Aβ)desensitivity
fHf = fH(1+Aβ),   fLf = fL/(1+Aβ)
  • Gain-bandwidth product stays constant.
  • Noise reduction needs a clean pre-amp stage; SNR improves by its gain.
  • Reduces nonlinear distortion. Cost: gain drops by (1+Aβ).
